# 1.0.12：一键操作与研究交接

控制端版本 1.0.12，插件仍为 2.5.9。

## 界面操作

- 每张服务器卡片新增“一键停止（数量）”：停止该服当前启用、仍持票或待清理的全部分配。停用状态先保存，然后等待会话结束、远程实体移除及票据清理；保留分配记录与 Steam 登录，不关闭 Rust 服务端进程。插件离线时显示待清理，恢复后自动清理。
- Steam 账号标题栏新增“一键退出全部”：无需勾选，处理当前列出的所有非退出中账号，包括离线但仍有等待分配的账号；先停止关联会话，再退出 Steam 并取消登录重试，账号及分配记录保留。单次超过 1000 个账号时分批提交，结果按账号反馈。
- 保留“退出选中”、单账号“退出”和“删除全部分配”。一键停止与删除分配作用不同，可按需要选择。
- 操作执行期间禁用重复点击；状态轮询重绘后仍保持进行中状态。批量退出期间暂停登录、导入及分配入口，避免界面上同时发起相反操作。
- 小屏账号标题栏换行，避免新增按钮挤出屏幕；页脚显示 1.0.12。

服务器一键停止新增 POST /api/servers/:id/stop。返回 stopped（本次停用/处理数）、pending（仍需远端清理数），有 pending 时为 HTTP 202，否则为 200。它不表示存在 pending 的远端实体已经移除。认证审计中的结束原因为 server_stopped；账号退出仍为 account_logout。

## 启动与迁移

新电脑解压后双击 start.cmd，依赖 Node.js 22+；新增账号和服务器后配对。发行包不携带 data，旧 Windows 用户保护的加密文件不可假定跨电脑可读。已有环境覆盖源码前正常停止控制端并保留自己的 data；若浏览器缓存了旧页面，更新后按 Ctrl+F5。插件为同一 2.5.9 时无需为本次界面变化重载。
